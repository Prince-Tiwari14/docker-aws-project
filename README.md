# Docker AWS Deployment

A full-stack web application containerized with Docker and prepared for deployment on AWS.

## Project Structure

- `Frontend` — frontend application
- `Backend` — backend API
- `dockerfile` — Docker configuration
- `aws-setup.pdf` — AWS setup reference
- `docker.pdf` — Docker reference

## Technologies

- React
- Node.js
- Docker
- AWS

## Project Overview

This project demonstrates how a frontend and backend application can be containerized using Docker and prepared for deployment on AWS.

## Local Setup

### Backend

```bash
cd Backend
npm install
npm start
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```
